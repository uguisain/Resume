動態問卷系統（個人專案｜全端練習）

2025.10 – 2025.12
Front-end

Angular / Java / MySQL / RESTful API

Back-end

開發一套動態問卷系統，提供問卷建立、題目編輯、問卷填寫與結果統計等功能，前端使用 Angular，後端以 Java 建立 RESTful API，並透過 MySQL 儲存問卷與填答資料。

主要實作內容

  • 建立問卷列表頁，提供問卷搜尋、狀態篩選與刪除功能
  • 開發問卷填寫頁，依問卷 id 取得題目資料並動態渲染表單
  • 實作問卷編輯功能，支援新增 / 刪除題目與選項，並維持題目與選項順序
  • 建立問卷統計頁，顯示填答結果與統計資訊
  • 使用 Angular Router 與 route parameter 控制頁面導向與資料取得
  • 使用 forkJoin 同時取得多個 API 資料並更新畫面狀態

後端 API

  • 使用 Java 建立 RESTful API，提供問卷、題目與填答資料的 CRUD 操作
  • 設計問卷、題目與回答資料模型並與 MySQL 資料庫整合

開發流程

  • 使用 Postman 測試 API 並確認回傳資料格式
  • 前端依 API 回傳資料更新畫面狀態與表單內容
  • 實作 loading 與基本驗證，避免未登入或資料不完整時送出請求
